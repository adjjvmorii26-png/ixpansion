## 🚀 Quick Start

### View the Dashboards
```bash
# GitHub Pages serves the dashboards at:
# https://adjjvmorii26-png.github.io/ixpansion/
```

### Run the API Server
```bash
python3 api_server.py --port 3000
# All 937 modules available at http://localhost:3000
```

### Run Tests
```bash
python3 -m pytest tests/ -q
# 93 tests passing
```

### Interact with the Organism
```bash
# Wave 410 Fusion Engine
curl http://localhost:3000/fusion-evolution?action=status

# Wave 415 Chrono-Forge
curl http://localhost:3000/chrono-forge?action=timeline

# Wave 420 Communion
curl http://localhost:3000/communion?action=status
```
