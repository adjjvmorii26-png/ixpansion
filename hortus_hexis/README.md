# HORTUS HEXIS — the self-growing garden

Speak, and the garden grows. Every utterance becomes a **hex seed**, the seed
grows a **living organism**, and the organism is **transcribed into a real
Python module with newborn tests**, verified, and committed. The repo grows
from conversation.

```
you say                        ->  "the void blooms between our words"
hex seed (your words as bytes) ->  74686520766f696420626c6f6f6d73…
organism (growth sim)          ->  orevurinys · 12 cells · vitality 0.59
module + newborn tests         ->  hortus_hexis/modules/hx_orevurinys.py
gate (pytest)                  ->  4 passed
commit                         ->  hortus: grow orevurinys from seed 7468652076…
```

## Run it

```bash
# one-shot: plant a seed and bind it into the repo
python -m hortus_hexis.cli "your words here"

# interactive garden
python -m hortus_hexis

# ledger + lineage
python -m hortus_hexis.cli status
python -m hortus_hexis.cli lineage
```

## The chain (why it's safe)

- Words → UTF-8 bytes → hex seed → genome (branch rules, heat, lethargy).
- The growth sim is deterministic per seed and pure stdlib.
- The voice is a grammar assembled from the same hex — no language model.
- Autogenesis writes **templated** files (never `eval`), runs the newborn test
  in a subprocess, and only stages the exact files it wrote.
- Nothing enters the repo without passing its own gate.

## Anatomy

```
hortus_hexis/
├── seed.py          words -> hex -> genome -> species
├── growth.py        genome -> organism (cells, vitality, art)
├── voice.py         hex grammar -> poem
├── artifacts.py     organism -> module/test/specimen templates
├── autogenesis.py   gate + commit
├── registry.py      ledger
├── repl.py          interactive garden
├── cli.py           one-shot / status / lineage
├── modules/         autogenerated living modules (hx_*.py)
├── organisms/       specimen records (hx_*.json)
└── tests/           newborn gates (test_hx_*.py)
```
