# Solid Organism Labs

Five deterministic, dependency-free experiments that make structural metaphors
runnable and auditable.

| Experiment | Idea |
|---|---|
| `lab/kintsugi.py` | Repairs artifacts while preserving and strengthening their fracture history |
| `lab/constellation_dice.py` | Places stars from a seeded throw and names the resulting graph |
| `lab/cordyceps.py` | Models relay spread where explicit refusal becomes immunity memory |
| `lab/negative_space.py` | Scores empty lattice cells by the pressure of neighboring presence |
| `omega/experiments/mood_superposition.py` | Collapses synthetic mood vectors; explicitly not a claim of feeling |

Run all of them through the commands in the root README.
