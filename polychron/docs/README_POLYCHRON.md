# POLYCHRON ATLAS

**Multi-temporal cartography & paradox-weaving engine**

Polychron Atlas maps overlapping temporalities through Glyphstreams, weaves contradictions on a Paradox Loom, sustains resonances in a Harmonic Array, grows void fruit in a Null Orchard, deliberates via an Echo Parliament, and stores dimensional states in a Horizon Vault.

## Core Principles

1. **Glyphs encode time** — each glyph carries a temporal signature.
2. **Paradoxes are woven, not resolved** — tension is productive.
3. **Harmonics stabilize the map** — phase-locked resonances hold the atlas coherent.
4. **Void fruit grows in null space** — absence becomes generative.
5. **Parliament deliberates** — four echo agents reach consensus before the atlas advances.
6. **Vaults remember dimensions** — collapsed states remain recoverable.

## Quick Start

```bash

./atlas_boot.sh
```
