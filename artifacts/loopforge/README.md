# LOOPFORGE Artifact Shelf

Store generated media and experiments here only when the repository's size and licensing rules permit it. Large binary media should use the approved artifact store rather than Git.

Each artifact record should include:
- stable artifact ID and version;
- source or parent asset ID;
- creator or source attribution and license/provenance;
- prompt/seed and generator identifier, when applicable;
- dimensions, frame count, FPS, duration, and format for motion media;
- content-safety review state;
- test or visual-review evidence;
- retention and publication status.

Never store secrets, private personal data, or unlicensed source media. Keep quarantined material out of public galleries. A preview thumbnail is not proof of the full asset's integrity.
