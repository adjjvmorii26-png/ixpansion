# Wave 907 — Branch Atlas

Wave 907 turns lineage records into a deterministic topology atlas.

It exposes roots, leaves, branch points, depth, terminal paths, and orphan
parent references. It is descriptive: it does not rank branches, declare
truth, infer causation, or assign quality.

The same records produce the same ordered atlas, making the output suitable
for later Nexus Observatory visualization and replay-oriented experiments.
