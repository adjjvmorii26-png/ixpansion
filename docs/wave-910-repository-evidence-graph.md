# Wave 910 — Repository Evidence Graph

Wave 910 connects the repository observatory to an explicit provenance graph.

It records observations, supporting evidence, and relationships while preserving
candidate/uncertain status. The graph is deterministic and fingerprinted so the
same observation set can be replayed.

This layer intentionally does not infer semantic truth or resolve contradictions
by deleting one side. It prepares the repository for temporal and metamorphic
experiments.
