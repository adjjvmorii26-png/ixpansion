# Wave 913 — Metamorphic Evolution Lab

Wave 913 introduces controlled repository transformations and declared invariant
checks. The first experiments are deliberately small: identity and reordering.

A preserved invariant is an observation under the supplied transformation.
A violated invariant is a signal requiring investigation, not an automatic
regression verdict. Unsupported invariants remain unknown.

This creates the first controlled experiment surface connecting the temporal
diff and evolution ledger layers.
