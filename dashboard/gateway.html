API Reference

POST/gateway
Main endpoint. Send an API key + natural language query.

Request Body

{
  "api_key": "ixp_free_a1b2c3d4e5f6...",
  "query":   "what's the frontier's heartbeat?"
}

Or use an explicit route:

{
  "api_key": "ixp_growth_...",
  "route":   "/forecast"
}

Response

{
  "status": "active",
  "version": "3.77.0",
  "wave": "162",
  "gateway": {
    "route": "/health",
    "tier": "free",
    "owner": "your-name",
    "echo_count": 42,
    "remaining_daily": 9958
  }
}

Generate a Key

GET/gateway?signup=your-name
Returns a new free API key. Use the CLI for tier selection.
$ python3 gateway/router.py --signup your-name

Get Key Stats

GET/gateway?key=ixp_free_...&stats=1
