# SEAMWALK

**A tectonic interface for code realities.**  
Not a dashboard. You **walk seams** between plates (present modules) and rifts (intentional absences).

## Rules
1. Rifts are not bugs — click refuses to fill the void  
2. Cursor leaves a proof trail — walk distance is the only score  
3. No sound — mood colors the void  
4. No classic chrome — hold near a seam to witness it  

```bash
python apps/seamwalk/build_seams.py
python apps/seamwalk/serve.py
# http://127.0.0.1:8787/
```
