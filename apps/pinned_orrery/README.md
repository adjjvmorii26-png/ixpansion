# Pinned Orrery

Unique interactive instrument built from `lab/pinned_projects.json`.

- **Inner ring** — critical pins (smoke, pulse, sentinel, sandbox)
- **Outer ring** — optional experiments
- Click a star → path, args, sigil, critical badge
- Not a dashboard: a living orrery

```bash
python apps/pinned_orrery/serve.py
# open http://127.0.0.1:8766/
```

Or open `index.html` directly in a browser.
