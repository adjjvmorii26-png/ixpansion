# Connector Federation Lab v0.2.0

Private R&D toolkit for designing and testing connector adapters without mistaking schema parsing or fake-provider success for live integration proof.

## Included skills
- capability-contract-compiler: compile provider schemas into normalized contracts and acceptance matrices.
- federation-shadow-twin: compare baseline and candidate routes using identical deterministic fixtures.
- connector-chaos-simulator: exercise resilience with deterministic failures in local fake transports.
